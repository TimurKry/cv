# Relevant experience — long version

I use AI coding assistants as my main development workflow, not as an add-on.
Cursor and Claude are part of my daily work: reading unfamiliar code, planning
refactors, generating and converting markup, and reviewing my own output before
it ships.

**Legacy e-commerce frontend, backend left intact — Straumann Group (2023-2026)**

The closest match to your project is my modernization of the Straumann Order
Tool, an internal B2B ordering application. I redesigned the UI and UX, migrated
and adapted the legacy code, and added new validation rules and features, while
the existing ordering and data logic stayed untouched. That is exactly the
constraint you describe: replace the presentation layer, leave the cart and
backend logic alone.

Related work in the same role:

- A management tool that parses XML files and renders stock levels, product
  relationships and compatibilities as readable, scannable tables. Close to your
  requirement of turning large technical specification tables into something
  usable on a small screen.
- An office information display showing live KPIs on TV screens.
- Refactoring legacy modules written in Visual Basic .NET, a stack that was not
  my own. I am used to working inside an unfamiliar legacy codebase and
  preserving its behaviour rather than rewriting it.

**E-commerce storefronts — freelance, since 2020**

Seven client projects, several of them shops on Shopify, Webflow and Tilda. That
work is re-skinning by definition: customizing templates and themes on top of a
platform's existing cart and checkout, without touching the backend.

**Tailwind CSS, AI-assisted, on GitHub**

- github.com/TimurKry/dvizh-patrol — mobile-first PWA. Next.js 16, React 19,
  TypeScript, Tailwind CSS v4, Supabase, Mapbox. Includes a documented design
  system built from Figma and Playwright + Vitest test suites. Built end to end
  in an AI-assisted workflow with Cursor and Claude.
  Live: dvizh-patrol.vercel.app
- github.com/TimurKry/meeting-point-finder — React/TypeScript frontend with a
  Node.js backend aggregating several external REST sources, plus Google Gemini
  API for ranking.

Portfolio: ktimur-portfolio.netlify.app

One note for transparency: my backend experience is Node.js and SQL rather than
PHP. Working inside a custom or unfamiliar backend and preserving its logic is
something I have done, but I would not describe myself as a PHP developer.
